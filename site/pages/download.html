Core and offline installers

Core or offline: the same Keeper.

Core installer (smaller)

Leaves out three heavy tools that only some parts use: video tools, on-device AI and cloud connections. Keeper downloads each one when you switch on a part that needs it, and checks it the same way as an update.

Offline (everything inside)

Files ending in -full have every part inside, for computers without a network or if you'd rather download once. With the script, add -s -- --full after bash.

Just the command

The keeper command for terminals and scripts comes with every install. To get only the command, use --cli-only with the script (needs Node.js 22 or later).

Check a download

Know the file is the one we built.

The install scripts do these checks for you, and so does Keeper's updater. To check a file you downloaded yourself:

  1. Compare the checksum

    Download SHA256SUMS.txt from the same release, put it next to your file and run:

    shasum -a 256 --check --ignore-missing SHA256SUMS.txt

    On Linux use sha256sum --check --ignore-missing SHA256SUMS.txt. On Windows, compare the line for your file with Get-FileHash .\Keeper-setup-x64.exe.

  2. Check the Sigstore signature of the checksums

    SHA256SUMS.txt is signed by the release workflow without a long-lived key, and the signature is recorded in a public log. Download SHA256SUMS.txt.sigstore.json too and run:

    cosign verify-blob SHA256SUMS.txt --bundle SHA256SUMS.txt.sigstore.json \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity-regexp '^https://github.com/ashfordeOU/keeper/\.github/workflows/release\.yml@refs/(heads/main|tags/v)'

  3. Check where it was built

    GitHub records which workflow run built each file. With the GitHub CLI:

    gh attestation verify Keeper-mac-arm64.dmg --repo ashfordeOU/keeper

  4. On a Mac, check the signature

    From 1.0.0, Keeper is signed with Ashforde's Apple Developer ID (team D69G45342Y) and notarized:

    codesign -dv --verbose=2 /Applications/Keeper.app

    It should show Authority=Developer ID Application: Ashforde OU (D69G45342Y).

If a file does not check out, don't run it, and please tell us. More in the install guide.

Betas

Try the next version early.

Betas come out on GitHub as pre-releases before a version is final. Turn on Settings → Updates → Include beta versions, or install the newest beta with the script:

curl -fsSL https://raw.githubusercontent.com/ashfordeOU/keeper/main/scripts/install.sh | bash -s -- --beta

Package managers only ever get stable versions. A copy on betas follows betas until a newer stable version is out. Testers: see the beta guide.

Updates

Keeper updates itself. In Settings → Updates, choose automatically, ask first, or only when you check.

Every update must match the release's SHA256SUMS.txt before it is installed, and on a Mac it must be signed with Ashforde's Developer ID.
