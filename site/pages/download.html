Check a download

Know it's the file we built.

The install scripts and Keeper's updater check every file for you, updates included. To check one yourself:

  1. Compare the checksum

    Download SHA256SUMS.txt from the same release, put it next to your file and run:

    shasum -a 256 --check --ignore-missing SHA256SUMS.txt

    On Linux use sha256sum --check --ignore-missing SHA256SUMS.txt. On Windows, compare the line for your file with Get-FileHash .\Keeper-setup-x64.exe.

  2. Check the Sigstore signature of the checksums

    Download SHA256SUMS.txt.sigstore.json too and run:

    cosign verify-blob SHA256SUMS.txt --bundle SHA256SUMS.txt.sigstore.json \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity-regexp '^https://github.com/ashfordeOU/keeper/\.github/workflows/release\.yml@refs/(heads/main|tags/v)'

  3. Check where it was built

    With the GitHub CLI:

    gh attestation verify Keeper-mac-arm64.dmg --repo ashfordeOU/keeper

  4. On a Mac, check the signature

    Keeper is signed with Ashforde's Apple Developer ID (team D69G45342Y):

    codesign -dv --verbose=2 /Applications/Keeper.app

    It should show Authority=Developer ID Application: Ashforde OU (D69G45342Y).

If a file does not check out, don't run it, and please tell us. More in the install guide.
