What Keeper is

One app, made of parts you switch on and off.

Install Keeper once and choose what it does in Settings → Features. A part that is off doesn't run at all: no window, no timer, no work in the background.

Parts keep each other running

The Island, the widgets and Mail run on their own. If the main window stops, they stay on screen and mail keeps arriving.

A small download

Heavy tools that only some parts need (video, on-device AI, cloud connections) download when you switch those parts on. The offline installer has everything inside.

The same everywhere

macOS, Windows and Linux, plus the keeper command for terminals. Where a system can't do something, Keeper says so.

Install

On a Mac, one line does it.

Paste this into Terminal. It picks the right disk image for your Mac (Apple silicon or Intel), checks it against the release's checksums, puts Keeper in Applications and opens it.

curl -fsSL https://raw.githubusercontent.com/ashfordeOU/keeper/main/scripts/install.sh | bash

Rather use Homebrew? brew tap ashfordeOU/keeper https://github.com/ashfordeOU/keeper then brew install --cask keeper. Windows and Linux: every download.

Signed and notarized

From 1.0.0, Keeper for macOS is signed with Ashforde's Apple Developer ID and notarized by Apple. It opens like any other app: no Open Anyway step, and no keychain question after every update.
