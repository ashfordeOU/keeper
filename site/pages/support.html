Reporting a security problem

Please don't open a public issue for a vulnerability. Use Report a vulnerability on the repository's Security tab, which stays private. Include the version, your system, the steps and what you saw. We aim to reply within a week.

Keeper deletes caches and moves files to the Trash, so safety bugs matter to us as much as security bugs. We especially want to hear about:

  • any way to make Keeper delete, move or overwrite something it shouldn't, or delete files instead of moving them to the Trash;
  • ways for a web page, a file, the clipboard, an email or an AI reply to make Keeper run code or act on files;
  • passwords, keys or file contents leaving the computer.

Security fixes go into the latest release. The full policy and the latest security review are in SECURITY.md. To check that a download is genuine, see Check a download.
