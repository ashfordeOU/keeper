Keeper + Monorail

Two Ashforde apps that know about each other.

Monorail is Ashforde's scrolling window manager for Mac: every window gets a place on a strip that runs past the screen edges, so new windows slide in without squeezing the others. With Keeper on the same Mac, the two never get in each other's way.

Monorail's page about Keeper About Monorail

One Stay Awake

Start Stay Awake in either app and only one of them keeps the Mac awake, never both. While Keeper runs, Monorail hands the job to Keeper's Keep Awake and says so.

When Keeper starts a session and Monorail already has one you started, Keeper takes it over and tells you.

Lid closed, safely

Monorail can hand a closed-lid session to Keeper, which keeps a MacBook running with the lid shut. Same rules in both apps: only while plugged in, and off when it gets hot or in Low Power Mode.

If Keeper can't (setup missing, or permission refused), it starts nothing and says why, and Monorail keeps the Mac awake itself.

Keeper's panels left alone

Monorail never tiles, moves or pushes off screen the Island, the clipboard picker, widgets, the wallpaper, Stage and Keeper's other panels. Keeper's main window still tiles like any other window.

Focus and presenting, in step

A Focus session in Keeper switches on Monorail's Focus mode, and the other way round. Stage switches on Monorail's presentation mode, so its notices stay out of recordings.

No shortcut clashes

Keeper compares its keyboard shortcuts with Monorail's. When two clash, it suggests a free key and changes Keeper's with one click; Monorail's keys are never changed.

One updater, on your Mac only

Keeper can install Monorail, and updates it only when Monorail's own updates are off. The two talk to each other on your Mac only, and nothing about your windows or files leaves it.

Turning it on

Nothing to set up. Keeper's panels are left alone whether or not you change anything. The rest uses the Monorail switch in Keeper → Settings → Features, which turns on by itself the first time Keeper finds Monorail installed. If you turn it off, Keeper never turns it back on.

The hand-overs need Monorail 1.7.9 or later. With an older Monorail, Keeper still keeps its panels out of the way. Every detail, for the curious: KEEPER-MONORAIL.md.
